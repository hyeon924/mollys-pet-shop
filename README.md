# Molly's Pet Shop 웹사이트 리팩토링

기존 몰리스 펫샵 퍼블리싱 자료를 React 기반으로 마이그레이션하고, 반려동물 쇼핑몰의 상품 탐색 흐름을 유지하면서 반응형 UI와 인터랙션을 개선한 개인 프론트엔드 프로젝트입니다.

**배포 사이트:** https://hyeon924.github.io/mollys-pet-shop/

> 본 프로젝트는 개인 포트폴리오 및 학습 목적으로 제작한 리팩토링 작업물입니다. Molly's Pet Shop 및 관련 브랜드가 운영하는 공식 웹사이트가 아니며, 원본 콘텐츠·이미지의 권리는 각 권리자에게 있습니다.

## 소개

기존 정적 HTML/CSS/jQuery 기반 화면을 React와 Vite로 전환했습니다. 메인 화면에는 브랜드 소개, 서비스, 추천·행사 제품 슬라이더를 구성했고, 강아지 상품 목록에는 연령 필터·정렬·페이지네이션 기능을 구현했습니다.

## 주요 화면

- **홈:** 브랜드 소개, 반려견 미용·스파, 호텔·놀이터 서비스, 메인 비주얼 슬라이더, 추천제품 및 행사제품 슬라이더
- **강아지 상품 목록:** 카테고리 UI, 연령 필터, 판매량·추천·가격순 정렬, 페이지네이션
- **반응형 내비게이션:** 데스크톱 드롭다운 메뉴와 모바일 가로 메뉴 UI
- **인터랙션:** 메인·상품 캐러셀, 맨 위로 이동 버튼, 메뉴·상품 카드 호버 효과

## 기술 구성

- React
- Vite
- JavaScript
- CSS
- GitHub Actions / GitHub Pages

## 프로젝트 구조

```text
src/
├── components/   # 공통 레이아웃 및 UI 컴포넌트
├── data/         # 상품 콘텐츠 데이터
├── pages/        # 메인 및 강아지 상품 목록 화면
├── styles/       # 전역 스타일
├── utils/        # 이미지 자산 경로 유틸리티
├── App.jsx       # 해시 기반 화면 전환 및 공통 레이아웃 조합
└── main.jsx      # React 진입점
public/
├── img/          # 메인 화면 이미지 자산
└── img_sub/      # 상품 목록 이미지 자산
```

## 배포

GitHub Pages를 통해 배포합니다. `main` 브랜치에 변경 사항이 반영되면 GitHub Actions 워크플로가 프로덕션 빌드와 배포를 진행합니다.
